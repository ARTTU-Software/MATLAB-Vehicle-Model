# SimulationStudies instructions

Use the project [vehicle-model-studies skill](../.agents/skills/vehicle-model-studies/SKILL.md) for study work, rehearsals and workflow maintenance. Read it directly if it is not listed as an available skill. The root [AGENTS.md](../AGENTS.md) supplies the project-wide scope and approval rules.

The detailed procedure is maintained in [WORKFLOW.md](WORKFLOW.md), and model mappings/history in [MODEL_WORKSPACE.md](MODEL_WORKSPACE.md). Read both before preparing, changing, running or post-processing a study, or explaining a rehearsal.

Maintain shared inventory, runner templates and historical preview data in place. Study-specific code and reviewed template snapshots belong in the study folder. Follow the workflow for stage approvals, selected-signal storage, evidence-based stop labels and cleanup; loading these instructions does not authorize a simulation.
