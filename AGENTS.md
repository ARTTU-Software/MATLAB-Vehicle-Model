# Vehicle Model project instructions

Preserve existing user changes and unsaved MATLAB work. For simulation studies, use temporary per-run overrides; edit original models, workbooks or parameter scripts only when the user requests those edits.

For simulation-study planning, preparation, validation, execution, reruns, post-processing or workflow maintenance, use the project [vehicle-model-studies skill](.agents/skills/vehicle-model-studies/SKILL.md). Read that file directly if it is not listed in the available skills. Ordinary model or MATLAB edits alone do not require the study workflow.

Respect the requested scope. A documentation-only rehearsal reads Markdown and explains the procedure; it must not access MATLAB or model/data files, refresh inventory, generate previews, create a study or modify project files. A request to maintain the workflow authorizes the requested file edits, not a study run.

Study execution requires approval for short validation, presentation of its findings, then separate approval for full execution. Do not run full-length validation. Do not reuse earlier-study approvals or repeatedly ask within an already approved stage. Loading the skill, preparing files or editing JSON does not authorize simulation. Follow explicit user changes to these defaults within their stated scope.

Keep the detailed procedure in [SimulationStudies/WORKFLOW.md](SimulationStudies/WORKFLOW.md) and model mappings/history in [SimulationStudies/MODEL_WORKSPACE.md](SimulationStudies/MODEL_WORKSPACE.md). The skill routes to those maintained sources; do not create duplicate inventories, runners or preview archives.
